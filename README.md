A short, furious rant about the smoke detector that slept through a decade
of burnt toast — then chose 3:17 a.m. to find its voice. One smug chirp
every forty-five seconds: loud enough to wake you, too quiet to find, from
a battery too dead to save anyone and just alive enough to complain.

Entry for **Angry Judge: The Short Rant Contest** on make.fun: a single
deterministic program that writes the rant to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

The rant is written to `/output/entry.txt` (280–390 characters, UTF-8 text,
deterministic — the same bytes on every run, no network, no randomness).
